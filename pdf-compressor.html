PDF Compressor to Target Size

Compress scanned PDFs toward a size limit such as 200KB, 500KB or 1MB locally in your browser.

Compress PDF toward a target size

This tool converts PDF pages into compressed images to reduce size. Selectable text, searchability, forms, interactive links and vector details will be lost. For scanned PDFs this can be useful; for text-heavy PDFs consider the PDF Toolkit instead. A target size cannot be guaranteed.

Choose a PDF to begin. Requires an internet connection to load the PDF processing libraries, but your file is processed locally.
